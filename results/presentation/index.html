01Setup

Sequence\(\mathcal{M}^{(1)}, \mathcal{M}^{(2)}, \ldots, \mathcal{M}^{(K)}\) with \(K = 10\); each MDP has shared \(\mathcal{S}, \mathcal{A}\), task-specific \(P^{(k)}, \mathcal{G}^{(k)}\).
Reward\(r_g(s_t, a_t) \;=\; (1-\gamma)\, p\!\left(s_{t+1} = g \,\middle|\, s_t, a_t\right)\) — sparse goal-reaching only.
Goal\(\max_{\theta}\;\mathbb{E}_{k}\,\mathbb{E}_{g \sim \mathcal{G}^{(k)}}\,\mathbb{E}_{\tau \sim \pi_{\theta}^{(k)}}\!\left[ \sum_{t=0}^{T} \gamma^{t}\, \mathbf{1}[s_{t+1}=g] \right]\) after observing \(\mathcal{M}^{(1..k)}\) in order.
CriticContrastive InfoNCE on \((s, a, g)\) with hindsight relabelling and in-batch negatives.

03Training pipeline

Algorithm 1 — Continual contrastive GCRL with a decomposed critic
input tasks M⁽¹⁾..M⁽ᴷ⁾; budget N per task; aux weight μ; mask M ⊆ dim(S) init shared (b_shared, h_φ, h_dyn, ψ) ← random; targets ← params for k = 1, …, K: # task curriculum φ_task ← random; π_θ ← random; D_k ← ∅ # reset task-local state while env_steps_k < N: ────── rollout ────── τ ← rollout(π_θ, M⁽ᵏ⁾) D_k ← D_k ∪ HER_relabel(τ) # future-strategy ────── inner block (lax.scan over N_sgd mini-batches) ────── for i = 1, …, N_sgd: {(s, a, g, s′)} ~ D_k u = h_φ(b_shared(s, a)) + φ_task(s, a) # sa_repr v = ψ(g) L_NCE = − log softmax(uᵀv) # diag positives, batch negatives L_dyn = ‖ h_dyn(b_shared(s, a)) − s′[M] ‖² θ_critic ← Adam.step(θ_critic, ∇(L_NCE + μ·L_dyn)) θ_actor ← Adam.step(θ_actor, ∇L_actor(target critic)) # SAC dual update targets ← polyak(targets, params) ────── task boundary k → k+1 ────── save shared (b_shared, h_φ, h_dyn, ψ); drop φ_task, π_θ, D_k

Only φ_task, the actor πθ, and the replay buffer Dk reset at the task boundary. Everything else — the shared body bshared, the heads hφ and hdyn, the goal encoder ψ — carries forward. Polyak target updates run on the shared components only.
